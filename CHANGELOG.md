# Changelog

## v0.4.2 — stable personal-use baseline

Preserves the accepted direct-on-device live viewer: default ten-camera SD wall, 4/8/10/16 layouts, HD single-camera enlargement, explicit remote focus/Enter/Back, display framing controls, original app icon, shared bounded decoder and persistent rendering.

The sanitized source distribution introduces a neutral app namespace, one ignored private connection file with a safe example, generated transport instead of a vendored bundle, offline tests, private build/package validation, simulator-only tooling, publication checks, and next-LLM documentation.

This source export has not replaced the user's installed TV application. Historical hardware observations belong to the accepted baseline; fresh source/export verification is recorded in `docs/VALIDATION.md`. No camera images, private logs, credentials, vendor decoder payloads or IPKs are release assets.

Known performance, capture synchronization, aspect metadata and licensing limits remain explicit in the baseline/roadmap. Stable does not mean feature parity with a mobile surveillance app.
